# MaintAI 登录后前端 UI 模板迁移设计

## 目标

将 `C:\Users\c3223\Desktop\fix-\fix-` 中的登录后用户端与管理端 UI 设计迁移到当前项目 `fix-`，使当前项目在登录后采用模板的视觉语言和响应式布局，同时保留当前已有业务能力。

## 明确边界

### 保留不变

- 现有登录页及登录页相关视觉、表单和鉴权流程。
- 当前路由路径、路由守卫和登录重定向逻辑。
- 当前 API 地址、请求封装、数据模型和表单提交行为。
- WebSocket 通知、任务托盘、AI 对话流式输出与 keep-alive、语音控制和退出登录清理逻辑。
- 现有页面中的业务组件、数据加载、分页、筛选、上传、审核和图谱交互能力。

### 迁移范围

- 用户端布局和登录后页面的视觉结构、导航、头部、内容容器、卡片、按钮、表格、表单和空状态样式。
- 管理端布局和登录后页面的视觉结构、导航、头部、内容容器、统计卡片、面板、表格、表单和响应式样式。
- 模板中的公共视觉 token、字体层级、间距、圆角、边框、阴影、蓝色品牌强调色和移动端导航表现。
- 与上述 UI 对应的公共样式资源（不覆盖登录页专用样式）。

## 实现方案

采用“视觉迁移、逻辑保留”的混合方式，而不是直接覆盖模板页面：

1. 以模板 `UserLayout.vue` 和 `AdminLayout.vue` 的结构与 class 命名为视觉参考，迁移登录后外壳和导航表现。
2. 对用户端、管理端各页面优先复用模板的模板层和样式；保留当前页面的 `<script setup>`、数据源、事件处理和功能组件。
3. 对模板中不存在或当前项目额外提供的功能（例如任务托盘、主题切换、AI 对话缓存）保留当前实现，并让它们适配新的视觉容器。
4. 将模板的公共 CSS 作为登录后视觉层接入；通过登录后根容器限定选择器，避免污染登录页。
5. 不改 API 文件、路由路径和后端代码。

## 页面映射

### 用户端

- `UserLayout.vue`：顶部品牌、主导航、搜索、在线状态、用户菜单、移动端菜单。
- `UserDashboard.vue`：欢迎区、统计卡片、快速检索、任务流、AI 助手和最近动态。
- `UserSearch.vue` / `UserSearchResult.vue`：搜索头部、筛选区、结果卡片和状态反馈。
- `UserKnowledgeGraph.vue`：图谱画布容器、工具栏和信息面板。
- `UserAIChat.vue`：聊天工作区、会话区、消息和输入区的视觉统一。
- `UserQuiz.vue` / `UserCaseUpload.vue`：练习与经验上传表单、反馈和状态样式。
- `UserTasks.vue` / `UserTaskDetail.vue`：任务列表、任务详情、步骤和操作状态样式。
- `UserProfile.vue`：个人资料、账号设置和安全区域样式。

### 管理端

- `AdminLayout.vue`：顶部品牌、管理导航、搜索、在线状态、用户菜单、移动端菜单。
- `AdminDashboard.vue`：管理欢迎区、统计卡片、检索指令区、任务状态、AI 助手和动态面板。
- `AdminKnowledge.vue` / `AdminKnowledgeCenter.vue` / `AdminKnowledgeGraph.vue`：知识中心、图谱和管理面板样式。
- `AdminTasks.vue`：任务列表、筛选、审核和状态反馈样式。
- `AdminSystemCenter.vue` / `AdminUsers.vue` / `AdminNotify.vue`：系统、用户、通知管理界面样式。
- `AdminProcedures.vue` / `AdminDomainRules.vue` / `AdminAnswerFeedback.vue` / `AdminAIChat.vue` / `AdminProfile.vue`：沿用业务逻辑，统一模板视觉层。

## 交互与响应式要求

- 桌面端保持模板的宽内容区、顶部导航和卡片网格。
- 窄屏下导航收起为移动端菜单，内容区不出现横向滚动。
- 可点击控件保持明显 hover、focus 和 active 状态；图标按钮提供 `aria-label` 或可见提示。
- 遵循模板的浅色背景、白色表面、蓝色主色和低对比边框；不使用 emoji 作为结构性图标。
- 保留 `prefers-reduced-motion` 兼容，迁移后的动画不阻塞数据加载或业务操作。

## 验证

1. 运行 `npm run build`，确认无编译错误。
2. 检查登录页截图或 DOM 样式未被登录后公共样式污染。
3. 使用普通用户和管理员账号分别访问主要用户端/管理端路由，确认路由守卫、导航和退出登录正常。
4. 检查搜索、任务、AI 对话、知识图谱、上传和通知等已有功能仍能触发原有请求与状态更新。
5. 检查桌面宽屏、平板宽度和移动端宽度下布局无明显溢出。

## 非目标

- 不新增后端接口、数据库字段或业务流程。
- 不重做登录页、忘记密码页或未登录首页。
- 不根据模板文档额外实现尚未存在的业务功能。
